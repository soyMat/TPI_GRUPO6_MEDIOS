# Inicio de BUILD CU_01 — Paquete de instrucciones para agentes

Este ZIP **no es código de la aplicación**: contiene las instrucciones para que Codex y los compañeros trabajen sobre el repositorio existente. Está basado en el RFC final v9.3 y las reglas `AGENTS.md` + `SDD_PLAYBOOK.md` de la cátedra.

1. Abrí **`PROMPT_PRINCIPAL_CODEX.md`** y pegá su texto completo en el chat Codex del VS Code que tiene abierto `TPI_GRUPO6_MEDIOS`.
2. Codex debe inspeccionar Git, duplicados y documentos; pedirte autorización antes de limpiar archivos o programar.
3. Después de aprobar la preparación, Codex creará las cuatro guías bajo `documentacion/TPI_GRUPO6_ETAPA4/Equipo/` y te ayudará a implementar tu rama de **Integrante 1**.
4. La carpeta contiene los cuatro Markdown ya redactados como base **para evitar que Codex los reinvente o use las guías antiguas desactualizadas**. Podés copiar esos archivos a `Equipo/` o dárselos de contexto a Codex. Si lo hace Codex, comparar con esta fuente y con la estructura real del repositorio.
5. Todos deben esperar a que los documentos y contratos base queden integrados a `main` antes de comenzar cuatro ramas en paralelo.

**Precaución:** la marca `U` en VS Code significa no rastreado (untracked), no "subido". Nunca usar `git clean -fd` ni eliminar fuentes sin comparar. No subir el ZIP de estas instrucciones ni duplicar RFC final dentro de `documentacion/`.
